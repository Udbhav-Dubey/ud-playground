# ud-playground

A personal playground for experimenting with C++, systems concepts, and small ideas.

This repository is intentionally messy and exploratory.  
It exists as a scratchpad where I try things out, break them, rewrite them, and move on.

Larger or more structured projects eventually get extracted into their own repositories.

---

## What this repo is

- A **curiosity-driven lab**
- A place for **experiments, prototypes, and learning code**
- A dumping ground for ideas before they grow up

This is not meant to be polished, production-ready, or consistent.

---

### 🧪 Small C++ Experiments
Scattered single-file programs exploring random ideas, such as:
- ASCII / terminal output experiments
- Geometry or rendering tests
- Networking requests
- Miscellaneous logic tests

Examples:
- `checking_cube.cpp`
- `checking_donut.cpp`
- `moving_text.cpp`
- `random.cpp`

These files usually exist because a question came up and I wanted to test it quickly.

---

## Extracted Projects

Some projects originally started here but were later moved to their own repositories once they grew large enough:

- **Grid-based games (Snake, Maze)** → moved to a dedicated repo
- **POSIX HTTP server** → moved to its own repository
- **posix chat** → moved to its own repository 
- **custom memory allocators** → moved to its own repository 

This repo keeps only the early or experimental stages.

---

## Philosophy

This repository values:
- Exploration over cleanliness
- Learning over structure
- Speed over polish

If you are browsing this repo:
- Expect rough edges
- Expect unfinished ideas
- Expect code written purely to understand something

That’s the point.
